# 提出物の venv は --system-site-packages 付きで作られるため、ここに書かない
# パッケージは採点イメージにプリインストールされている版がそのまま使われる
# （ルート README の「requirements.txt の書き方」）。
#
# torch と numpy は **意図的に書いていない**。
#   - torch: 書かないことでイメージの 2.11.0+cu130 が使われ、CUDA 13 の
#     ライブラリと整合する（ルート README の「CUDA 12 系の torch を使用する

#     イメージの 1.26.4 を隠して torch と ABI が食い違う恐れがある。
#     numpy は lerobot が自身の制約付きで引くのでそちらに任せる。
#
# fastapi / uvicorn / msgpack は policy_server.py が直接 import するため、
# 付録の「イメージ側に入っていることを前提にしない」に従って明示する。
# 版はイメージ側に合わせたいので固定しない。
#
# lerobot は 0.4.4 を指定する。0.5.0 以降は Python 3.12 以上を要求し、
# 採点イメージの Python 3.10 には入らない。
#
# transformers は 4.53.2 に固定する。lerobot 0.4.4 の pi0.5 は fork 版
# （git+ 指定。提出物では使えない）を前提にしているため、素の 4.53.2 を入れて
# 差分を policy_server.py の _install_transformers_shim() で補う。
# lerobot の transformers-dep extra（>=4.57.1）は使わないこと。
#
# 注意: lerobot 0.4.4 は torch<2.11.0 を要求するため、イメージの
# torch 2.11.0+cu130 は条件を満たさず、CUDA 12 版の torch が venv 側に
# 入る。ルート README の「CUDA 12 系の torch を使用する場合の注意」に
# 従い、nvidia-nvjitlink-cu12 を含む cu12 の wheel 一式がそろうことを
# Docker 上で必ず確認すること。
