## Gradient accumulation に関する未確定点

smoke script は `GA=2` を設定し、パッチも適用済み。ただし trainer 標準ログには:

`Effective batch size: 2 x 1 = 2`

と表示され、step 20 時点の `smpl` 表示は 40 だった。

この表示だけで gradient accumulation が効いていないとは断定できない。現行 LeRobot の effective batch / MetricsTracker ログは `gradient_accumulation_steps` を表示計算に含めていないためである。一方、smoke script 自身のコメントどおり、checkpoint の step 番号一致だけでも GA の実動作証明にはならない。

したがって full training 前に、optimizer step 回数または micro-step 数を直接観測する小さな検証を追加する価値がある。
